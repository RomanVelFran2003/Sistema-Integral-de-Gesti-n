# Sistema Integral de Gestión de Clientes, Servicios y Reservas - Software FJ

## Descripción
Sistema orientado a objetos para la gestión de clientes, servicios y reservas de la empresa Software FJ, implementado en Python con manejo avanzado de excepciones y logging.

## Características
- Arquitectura orientada a objetos completa
- Manejo robusto de excepciones personalizadas
- Logging profesional con múltiples niveles
- Validaciones estrictas de datos
- Simulaciones completas del sistema
- Sin uso de bases de datos
